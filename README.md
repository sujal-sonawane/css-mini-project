# CSS Mini Project

## Overview

A beginner-friendly photography-themed web interface created using HTML5 and CSS3. This project focuses on practicing CSS fundamentals by designing a full-screen layout with a background image, sidebar navigation, icons, hover effects, transitions, and a CSS-based menu toggle.

The project was created as part of my frontend development learning journey to understand how CSS can be used to transform a basic HTML structure into a visually organized web interface.

## How It Works

The project uses a hidden checkbox to control the sidebar state without JavaScript.

When the menu button is clicked, the checkbox state changes. CSS then uses the `:checked` pseudo-class and sibling selector to move the sidebar into view.

The main styling is handled through `style.css`, which controls the background image, sidebar positioning, typography, spacing, hover effects, transitions, and visual appearance.

## How to Run

2. Open the project folder.
3. Double-click `index.html`.
4. The project will open in your default web browser.

2. Open `index.html`.
3. Right-click the file.
